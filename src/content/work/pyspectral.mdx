## Problem

The FFT roofline (the FFTs of a step as standalone cuFFT calls, plus the minimal pointwise traffic) says how fast a step can possibly be. The code is checked against exact solutions and the Re = 1600 Taylor–Green reference.

## Approach

- 2D vorticity and 3D rotational-form Navier–Stokes, 2/3 dealiasing, integrating-factor RK4.
- Eleven backend variants from NumPy to hand-written CUDA C.
- Head-to-heads with JAX-CFD (GPU), spectralDNS (CPU, MPI) and the GPU branch of Dedalus, each verified against pyspectral first.

## Results

<Results metrics={frontmatter.metrics}>
  The fused in-place CUDA C path reaches the FFT roofline; Triton and Warp reach 76–80 %, limited by the out-of-place FFT calls they go through. JAX-CFD solves the same 2D problem 1.9–2.5× slower on the same GPU. See the [paper](https://github.com/walidhemati/pyspectral/blob/master/paper/paper.pdf).
</Results>
