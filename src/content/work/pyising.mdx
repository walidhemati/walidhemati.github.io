## Problem

Ising Monte Carlo is bound by memory traffic and random-number generation. Because every backend uses the same counter-based random stream, the same seed gives the same lattice on NumPy, PyTorch, Triton, Warp, Numba and CUDA C, which makes correctness checks exact.

## Approach

- int8 checkerboard and 1-bit multi-spin coding; Metropolis and heat bath; 2D and 3D; Wolff cluster updates for validation.
- Lazy bitwise uniforms: lanes stop drawing random bits as soon as their decision is fixed, with the exact Metropolis probability.
- Validation against the exact finite-lattice energy, Onsager–Yang magnetisation and Binder crossings in 2D and 3D.
- Head-to-head with NVIDIA ising-gpu (Romero et al. 2020, Bisson et al. 2025), built for this GPU.
